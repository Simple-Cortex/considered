# Considered: frame

Stage `frame` of the Considered chain. The root skill (`../../SKILL.md`) routes; this file only names the contract.

**Required input:** product context, the requested surface or target, the user request.

**Durable output:** `.considered/<surface-id>/FRAME.md` — brief score, one decision, one mode, surface route, dashboard type where it applies, Q inventory, object model, assumptions, blockers.

**Read, in order:**

1. `../../references/workflow.md` §2, §3 (routing), §4 `frame` and its brief gate loop, §5.
2. `../../assets/templates/FRAME.md` — the eight-dimension rubric lives here.
3. `../../references/modes.md` only if the mode is unclear or collides; `../../references/forms.md` for flows.

**Brief gate:** score first. Below 8 of 16, run the collaborative loop in §4 before designing. Never design below 8 silently.

**Block only when** equally supported routes would materially change P0, action, safety, or delivery and evidence cannot resolve them.
